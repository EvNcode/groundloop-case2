# GroundLoop

Операционная консоль для кейса Global Coffee × Coyote о переработке кофейного жмыха.

## Возможности

- журнал сбора с разделением измеренного и оценочного веса;
- синтетические данные для 18 точек и пилота на 6 точках;
- импорт CSV/XLSX и экспорт JSON;
- формирование маршрута и завершение сбора;
- создание прослеживаемой партии, производственный поток и выпуск;
- сценарная экономика с редактируемыми параметрами;
- публичный паспорт партии для QR на упаковке;
- локальный демо-режим и подготовленный общий контур Supabase Auth + PostgreSQL.

## Подключение Supabase

1. Создайте проект Supabase и примените [схему](supabase/schema.sql) через SQL Editor.
2. В [конфигурации](dist/supabase-config.js) задайте Project URL и publishable key. Secret/service-role key в клиентский файл не добавляйте.
3. Опубликуйте сайт, зарегистрируйте первого сотрудника и подтвердите его почту.
4. В Auth → Users скопируйте UUID сотрудника и выполните заключительный `insert` из схемы с ролью `admin`. Остальных сотрудников добавляйте в `groundloop_members` с ролью `operator` или `viewer`.

При заполненной конфигурации приложение требует вход, загружает общее состояние пилота из PostgreSQL и сохраняет правки с проверкой версии. При конфликте одновременных изменений интерфейс просит обновить страницу. Без конфигурации работает локальное демо. В текущем развёртывании Supabase пока не подключён.

## Локальный запуск

Откройте `dist/index.html` через любой статический HTTP-сервер. Например:

```powershell
npx --yes serve dist
```

## Проверка

```powershell
npm test
node --check dist/app.js
```

Все текущие объёмы, цены и технологические коэффициенты являются синтетическими допущениями и помечены в интерфейсе.
