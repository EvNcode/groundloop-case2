# GroundLoop

Операционная консоль для кейса Global Coffee × Coyote о переработке кофейного жмыха.

## Возможности

- журнал сбора с разделением измеренного и оценочного веса;
- синтетические данные для 18 точек и пилота на 6 точках;
- импорт CSV/XLSX и экспорт JSON;
- формирование маршрута и завершение сбора;
- создание прослеживаемой партии, производственный поток и выпуск;
- сценарная экономика с редактируемыми параметрами;
- публичный паспорт партии для QR на упаковке;
- локальный демо-режим и подготовленный общий контур Supabase Auth + PostgreSQL.

## Подключение Supabase

Проект `kofe` в EvN подключён, [схема](supabase/schema.sql) применена, а [конфигурация](dist/supabase-config.js) содержит только publishable key. Secret/service-role key в клиентский файл не добавляйте.

1. Зарегистрируйте первого сотрудника на сайте и подтвердите его почту.
2. Добавьте UUID из Auth → Users в `groundloop_members` с ролью `admin` (пример `insert` в конце схемы). Остальных сотрудников добавляйте с ролью `operator` или `viewer`.

Приложение требует вход, загружает общее состояние пилота из PostgreSQL и сохраняет правки с проверкой версии. При конфликте одновременных изменений интерфейс просит обновить страницу. До регистрации первого администратора доступ к рабочему экрану закрыт.

## Локальный запуск

Откройте `dist/index.html` через любой статический HTTP-сервер. Например:

```powershell
npx --yes serve dist
```

## Проверка

