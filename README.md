# GroundLoop

Демо полного пути кофейного жмыха для кейса 2 Global Coffee × Coyote: сбор на точках, хранение, вывоз, переработка, выпуск набора подставок и продажа. Все числа и операции в демо синтетические.

## Как работает

- Сайт открывается сразу, без логина и пароля. Supabase Auth создаёт анонимную сессию в фоне.
- Каждый посетитель получает отдельное рабочее пространство в PostgreSQL. Правки сохраняются после перезагрузки в том же браузере и недоступны другим посетителям через RLS.
- Прежняя рабочая база сотрудников не публикуется. Для неё добавлена ограничивающая политика, исключающая анонимные сессии.
- Сбор содержит источник веса, качество, код контейнера и время хранения. Готовые записи входят в маршрут; принятый материал поступает в партию.
- Партия проходит приёмку, сушку, контроль, формование и выпуск. Продажа уменьшает остаток, а база не позволяет продать больше произведённого.
- Экономика показывает месячную модель с редактируемыми допущениями. Журнал продаж показывает отдельные демо-операции и их выручку.
- Импорт CSV/XLSX, экспорт JSON и сброс собственного демо доступны в разделе «Данные».

## Стек

Статический HTML/CSS/JS в `dist/`; Supabase Auth, Postgres, RLS и триггеры как серверная часть. В клиенте находится только publishable key. SQL миграции в `supabase/`, новая демо-схема в `supabase/anonymous_demo.sql`.

## Запуск и проверка

```powershell
python -m http.server 8789 --directory dist
npm test
node --check dist/app.js
```

Публичная версия разворачивается GitHub Pages из `dist/` через `.github/workflows/pages.yml`. Для публикации в репозитории GitHub Pages должен использовать GitHub Actions как источник.

## Границы прототипа

Сайт даёт работающий цифровой процесс, спецификацию продукта и предварительный расчёт. Для полного финального результата по ТЗ нужно изготовить и испытать физический образец набора подставок и подтвердить объёмы жмыха, технологический выход, себестоимость и спрос замерами на точках. Интеграции с Coyote POS пока нет; импорт работает с отчётом CSV/XLSX.
