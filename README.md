# GroundLoop

Рабочая версия: https://evncode.github.io/groundloop-case2/

Демо полного пути кофейного жмыха для кейса 2 Global Coffee × Coyote: сбор на точках, хранение, вывоз, переработка, выпуск набора подставок и продажа. Все числа и операции в демо синтетические.

## Как работает

- Сайт открывается сразу, без логина и пароля. Supabase Auth создаёт анонимную сессию в фоне.
- Открытые посетители работают в общем рабочем пространстве PostgreSQL. Изменения подхватываются другими рабочими местами примерно раз в 3,5 секунды; одновременные правки проверяются по номеру ревизии.
- В переключателе есть рабочие места бариста, логистики, производства и управления. Бариста видит выбранную точку и записывает вес, логистика забирает контейнеры по точкам маршрута, производство подтверждает сухой вес и выпуск. Пока вход открыт, переключение роли ограничивает интерфейс, но не защищает данные от намеренного обхода.
- Прежняя рабочая база сотрудников не публикуется. Для неё добавлена ограничивающая политика, исключающая анонимные сессии.
- Сбор содержит источник веса, качество, код контейнера и время хранения. Маршрут можно создать только из проверенных контейнеров с положительным весом. Каждую точку вывоза подтверждают отдельно. Только завершённый маршрут поступает в партию.
- Партия проходит приёмку, сушку, контроль и формование. Сухой вес и фактическое число упаковок вводятся оператором. Продажа уменьшает остаток, а база не позволяет продать больше произведённого.
- Экономика показывает месячную модель с редактируемыми допущениями. Журнал продаж показывает отдельные демо-операции и их выручку.
- Импорт CSV/XLSX и экспорт JSON доступны в разделе «Данные» руководителю.

## Стек

Статический HTML/CSS/JS в `dist/`; Supabase Auth, Postgres, RLS и триггеры как серверная часть. В клиенте находится только publishable key. SQL для открытого общего пространства в `supabase/migrations/`. Ранее созданная приватная база сотрудников остаётся закрытой для анонимных пользователей.

## Запуск и проверка

```powershell
python -m http.server 8789 --directory dist
npm test
node --check dist/app.js
```

Публичная версия разворачивается GitHub Pages из `dist/` через `.github/workflows/pages.yml` при обновлении ветки `main`.

## Границы прототипа

Сайт даёт работающий цифровой процесс, спецификацию продукта и предварительный расчёт. Для полного финального результата по ТЗ нужно изготовить и испытать физический образец набора подставок и подтвердить объёмы жмыха, технологический выход, себестоимость и спрос замерами на точках. Интеграции с Coyote POS пока нет; импорт работает с отчётом CSV/XLSX.
